# Folio & Brew ☕📚

**Folio & Brew** is a modern and aesthetic café website built using **HTML** and **CSS**, designed to create a cozy digital experience for coffee lovers and book enthusiasts. The website combines a warm visual theme with a clean and responsive layout to represent a café where books and coffee come together.

## Features

- Elegant and responsive homepage design  
- Sticky navigation bar for smooth browsing  
- Hero section with engaging typography and call-to-action buttons  
- Menu section showcasing beverages and café offerings  
- Featured books section with categorized displays  
- About section introducing the café concept and timings  
- Warm and aesthetic color palette for a cozy user experience  
- Fully responsive design for mobile and desktop screens

## Technologies Used

- **HTML5**
- **CSS3**
- **Flexbox**
- **CSS Grid**
- **Responsive Design using Media Queries**

## Project Purpose

This project was created to practice:

- Front-end web development  
- Responsive web design  
- Website layout structuring using HTML and CSS  
- Creating modern and visually appealing user interfaces  
- Improving UI/UX design skills

## How to Run the Project

1. Download or clone the repository  
2. Open the project folder  
3. Open `index.html` in any web browser
